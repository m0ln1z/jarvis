# Jarvis

Голосовой ассистент для macOS, который управляет [Claude Code](https://docs.claude.com/claude-code) в ваших проектах.
Хлопаете дважды, говорите «Просыпайся, папочка вернулся» — и дальше голосом: открыть проект, дать задачу,
остановить, спросить, что там происходит, включить музыку и т.д. Руки на клавиатуре не нужны.

## Что умеет

- **Двойной хлопок + пароль** «Просыпайся, папочка вернулся» — будит Джарвиса. После этого 15 минут он отзывается на хлопок без пароля.
- **Проект + задача одной фразой**: «открой шоп бэкенд и добавь тёмную тему» — откроется окно Terminal, в нём Claude Code получит задачу.
- **Свободные команды** через «мозг» (Claude Haiku): «что там с бэкендом, он закончил?», «останови все проекты», «сделай потише», «найди в гугле…».
- **Перебить и дать новую задачу**: «стоп», «замолчи, лучше сделай…» — текущая работа прерывается, начинается новая.
- **Вопросы Claude голосом**: если Claude спрашивает «да/нет» или предлагает варианты, Джарвис пересказывает вопрос по-русски, вы отвечаете «да», «второй», «давай SQLite».
- **Озвучка результата**: когда Claude заканчивает задачу, Джарвис коротко говорит, что сделано.
- **Перебить Джарвиса** — один хлопок, пока он говорит.
- **Остановить Джарвиса**: клик по кругу на экране (при наведении — ✕) или голосом «выключись», «спи», «отбой», «всё, спасибо» — замолкает, бросает текущее и засыпает.
- **Иконка в строке меню**: цвет показывает состояние; в меню — «Слушать» (без хлопка), «Отменить», «Остановить Claude в текущем проекте», «Пауза» (микрофон выключается полностью — гаснет оранжевый значок macOS; «Слушать» работает и на паузе), настройки, лог, перезапуск, выключение.
- **Круг-«реактор» поверх экрана**: голубой — слушает, золотой с бегущими дугами — думает, пульсирует — говорит; под ним текст того, что услышано и что он отвечает.
- Проекты ищутся по звучанию: «шоп бэкенд» → `ShopBackend`, «сейлз экст» → `sales-ext`.

Claude Code запускается в режиме `--dangerously-skip-permissions` (без подтверждений), а папки проектов автоматически
отмечаются доверенными. Распознавание речи иногда ошибается — для рискованных задач поглядывайте в окно Terminal.

## Требования

- macOS (Apple Silicon или Intel)
- [Homebrew](https://brew.sh)
- [Claude Code](https://docs.claude.com/claude-code), вход выполнен (`claude` работает в терминале)
- Python 3.9+
- Микрофон и интернет (для голоса и мозга; распознавание речи работает локально)

## Установка

**Проще всего — готовый релиз:**
1. Скачайте `jarvis-*-macos.zip` со страницы [последнего релиза](https://github.com/m0ln1z/jarvis/releases/latest) и распакуйте.
2. Дважды кликните **`Install Jarvis.command`**. Если macOS не даёт открыть — правый клик → «Открыть» → «Открыть».

Джарвис скопируется в `~/jarvis`, поставит всё нужное и запустится в фоне.

**Одной командой в терминале:**

```bash
curl -fsSL https://raw.githubusercontent.com/m0ln1z/jarvis/main/get.sh | zsh
```

**Вручную:**

```bash
git clone https://github.com/m0ln1z/jarvis.git ~/jarvis
cd ~/jarvis
./install.sh
```

Установщик ставит `tmux` и `ffmpeg`, создаёт Python-окружение, команду `jarvis` и автозапуск при входе в систему.
При первом старте скачивается модель распознавания речи (~470 МБ).

macOS спросит разрешения — их нужно дать один раз:
- **Микрофон** — для Python / Terminal.
- **Автоматизация → Terminal** — чтобы Джарвис открывал окна.

## Настройка

Удобнее всего — **окно настроек**: иконка Джарвиса в строке меню → «Настройки…» (или `jarvis --settings`).
Там горячая клавиша (нажмите сочетание — оно запишется), пароль, модель мозга, папки проектов, голос с кнопкой
«Прослушать», ключ Fish Audio, все фразы, голосовые прозвища проектов и чувствительность хлопков.
Изменения применяются сразу, без перезапуска.

Те же настройки лежат в `config.json` (создаётся из `config.example.json` при первом запуске):

| Параметр | Что это |
|---|---|
| `projects_roots` | Где лежат проекты (по умолчанию `~/Desktop`) |
| `exclude` | Папки, которые не считать проектами |
| `aliases` | Как называть проекты голосом: `"ShopBackend": ["шоп бэкенд"]` |
| `tts` | Голос: `edge` (бесплатно, Microsoft) или `fish` (Fish Audio) |
| `voice`, `voice_rate`, `voice_pitch`, `voice_fx` | Голос для `edge` и его обработка (фильтры ffmpeg) |
| `fish.reference_id` | ID голоса Fish Audio (из адреса `fish.audio/m/<ID>`) |
| `hotkey` | Глобальная горячая клавиша: `alt+j` (по умолчанию), `ctrl+alt+space`, `cmd+shift+j`… |
| `wake_words` | Слова пароля (достаточно двух): `["просыпайся", "папочка", "вернулся"]` |
| `brain_model` | Модель мозга: `haiku` (быстрее) или `sonnet` (умнее) |
| `awake_minutes` | Сколько минут Джарвис не засыпает после пароля |
| `clap.min_level` | Порог громкости хлопка (подберите через `jarvis --levels`) |
| `phrases` | Что говорит Джарвис |

Изменения в `config.json` Джарвис тоже подхватывает сам в течение секунды.

### Голос Fish Audio

1. Получите API-ключ на [fish.audio](https://fish.audio/app/api-keys/).
2. Сохраните его в файл `.fish_key` в папке проекта (или в переменную окружения `FISH_API_KEY`):
   ```bash
   printf '%s' 'ВАШ_КЛЮЧ' > ~/jarvis/.fish_key && chmod 600 ~/jarvis/.fish_key
   ```
3. В `config.json` поставьте `"tts": "fish"` и нужный `fish.reference_id`.

Если Fish Audio недоступен, Джарвис говорит запасным голосом `edge`.

## Использование

| Сказать | Что произойдёт |
|---|---|
| *хлоп-хлоп* «Просыпайся, папочка вернулся» | «С возвращением, сэр. Какой проект открываем?» |
| «Открой шоп бэкенд и почини логин» | Окно проекта + задача Claude |
| «Добавь кнопку выхода» | Задача в текущий проект |
| «Стоп» | Остановить текущую работу |
| «Что там с бэкендом?» | Пересказ того, что делает Claude |
| «Включи музыку», «сколько времени?» | Мозг сам разберётся |
| **⌥J** в любом приложении | Слушает команду без хлопка и пароля; повторно ⌥J — отмена |
| *хлоп*, пока Джарвис говорит | Замолкает и слушает |
| «Выключись», «спи», «отбой» или клик по кругу | Замолкает и засыпает |

Полезные команды:

```bash
jarvis --levels        # уровни микрофона — подобрать порог хлопка
jarvis --enter         # тест без хлопков: диалог по Enter
jarvis --say "Привет"  # проверить голос
./jarvisctl sessions   # какие проекты открыты
tail -f jarvis.log     # что Джарвис слышит и делает
./install.sh --uninstall
```

## Как устроено

- `hud/` — круг на экране, иконка в строке меню и окно настроек (Swift) (собирается в `JarvisHUD` при установке, нужен `swiftc` из Xcode Command Line Tools).
- `jarvis.py` — детектор хлопков, распознавание речи ([faster-whisper](https://github.com/SYSTRAN/faster-whisper), локально), голос, диалог, мозг.
- Каждый проект — отдельная сессия Claude Code внутри `tmux` (конфиг `tmux.conf`): так Джарвис может нажимать Esc и вводить задачи.
- `on_stop.py` — хук Claude Code `Stop`: зачитывает итог ответа. Подключается только к сессиям, открытым Джарвисом.
- `jarvisctl` — команды, которыми мозг управляет проектами (`open`, `send`, `stop`, `status`, `close`).
